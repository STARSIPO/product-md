## Принципы

Интерфейс делового инструмента: простой, понятный, аккуратный, слегка премиальный. Пользователь должен разобраться без инструкции.

Красота достигается типографикой, отступами, структурой и качественными фотографиями — не украшениями.

**Чего в системе нет и не должно появиться:**

| Запрещено | Почему |
| --- | --- |
| Кислотные цвета, яркие градиенты | Площадка для закупок, а не развлекательный сервис |
| Огромные заголовки на весь экран | Отодвигают товары ниже сгиба; на главной первый экран — это поиск и каталог |
| Стопки теней, glassmorphism | Глубина создаётся границами, всего две ступени тени |
| Анимация ради анимации, параллакс, 3D | Отвлекает и мешает работать |
| Перегруженные карточки | Карточка отвечает на один вопрос: подходит товар или нет |
| Мелкий текст | Минимум основного текста — 15px, подписи — 13px |
| Изобилие иконок | Иконка только там, где ускоряет распознавание |
| Огромные пустые пространства | Плотность важнее «воздуха»: это каталог |

## Цвет

Все цвета — CSS-переменные в формате `R G B` (без функции `rgb()`), что позволяет Tailwind подставлять прозрачность через `<alpha-value>`. Перекрасить продукт можно, не трогая ни один компонент.

### Поверхности

| Токен | Переменная | RGB | HEX | Где |
| --- | --- | --- | --- | --- |
| `background` | `--color-background` | `247 247 245` | `#F7F7F5` | Фон страницы, тёплый светло-серый |
| `foreground` | `--color-foreground` | `22 25 28` | `#16191C` | Основной текст, почти чёрный |
| `card` | `--color-card` | `255 255 255` | `#FFFFFF` | Карточки, шапка, подвал |
| `muted` | `--color-muted` | `240 240 237` | `#F0F0ED` | Заливка вторичных блоков, skeleton |
| `muted-foreground` | `--color-muted-foreground` | `106 111 116` | `#6A6F74` | Вторичный текст |
| `border` | `--color-border` | `226 226 221` | `#E2E2DD` | Границы |
| `input` | `--color-input` | `214 214 209` | `#D6D6D1` | Границы полей ввода |

### Акценты

| Токен | RGB | HEX | Контраст | Где |
| --- | --- | --- | --- | --- |
| `primary` | `15 107 69` | `#0F6B45` | 6.4:1 на белом · 6.4:1 белым на нём | Главные действия, ссылки, активное состояние |
| `primary-hover` | `11 86 54` | `#0B5636` | 8.4:1 | Наведение на главную кнопку |
| `primary-soft` | `231 242 236` | `#E7F2EC` | — | Мягкая подложка выбранного состояния |
| `secondary` | `237 237 234` | `#EDEDEA` | — | Второстепенные кнопки |
| `accent` | `168 98 47` | `#A8622F` | 4.9:1 | Приглушённая терракота. Только «Срочно» и метка акции |
| `accent-soft` | `249 240 232` | `#F9F0E8` | — | Подложка акцента |

Зелёный выбран за ассоциацию со свежестью и сельским хозяйством, но намеренно приглушён — сайт не должен выглядеть как экоблог.

### Статусы

| Токен | RGB | HEX | Контраст на белом |
| --- | --- | --- | --- |
| `success` | `22 122 76` | `#167A4C` | 5.4:1 |
| `warning` | `166 98 12` | `#A6620C` | 5.0:1 |
| `destructive` | `176 35 31` | `#B0231F` | 6.1:1 |

У каждого есть `-soft` вариант для подложек. **Статус никогда не передаётся одним цветом** — всегда цвет + текст, а часто ещё и иконка.

## Типографика

Один шрифт — **Inter** (`next/font/google`, подмножества `latin`, `latin-ext`, `cyrillic`). Покрывает кириллицу и румынские диакритики `ă â î ș ț`. Второй шрифт не используется.

| Уровень | Класс | Размер | Интерлиньяж | Трекинг |
| --- | --- | --- | --- | --- |
| Display | `text-display` | 44px | 50.4px | −0.025em |
| H1 | `text-h1` | 34px | 40.8px | −0.02em |
| H2 | `text-h2` | 26px | 33.6px | −0.015em |
| H3 | `text-h3` | 20px | 28px | −0.01em |
| Крупный текст | `text-lg` | 17px | 26.4px | — |
| Основной | `text-base` | 15px | 24.8px | — |
| Мелкий | `text-sm` | 14px | 21.6px | — |
| Подпись | `text-caption` | 13px | 18.4px | — |

Правила:

- Заголовки — `font-semibold`, не `bold`. Жирным выделяется смысл, а не всё подряд.
- `text-wrap: balance` на всех заголовках — не даёт последнему слову висеть одиноко.
- Цены, количества и колонки таблиц — класс **`.tnum`** (`font-variant-numeric: tabular-nums`), чтобы цифры выстраивались по вертикали.
- Обрезка текста — `.clamp-1` / `.clamp-2` / `.clamp-3`.

> **Известное ограничение.** Поля ввода используют `text-base` = 15px. iOS Safari увеличивает масштаб при фокусе на поле мельче 16px. Исправляется точечным `text-[16px]` на контролах — сознательно не сделано, чтобы не ломать шкалу; решение за владельцем.

## Отступы и сетка

- Контейнер: центрированный, `max-width: 1320px`, боковые отступы `1rem → 1.5rem (sm) → 2rem (lg)`.
- Шаг сетки — Tailwind по умолчанию (0.25rem). Внутри карточки типичный отступ `p-3.5`/`p-4`, между секциями `py-10`.
- Сетка товаров: 1 колонка на 320px → 2 (`sm`) → 3 (`md`) → 4 (`lg`).
- Главная и каталог: липкая колонка категорий 248px слева + контент, начиная с `lg`.

## Скругления и тени

Скругления: `sm 6px`, `DEFAULT 8px`, `md 10px`, `lg 14px`, `xl 18px`.

Ступеней тени ровно **две**:

| Класс | Значение | Где |
| --- | --- | --- |
| `shadow-card` | `0 1px 2px rgb(16 24 32 / 0.04)` | Карточки, панели |
| `shadow-pop` | `0 8px 28px -6px rgb(16 24 32 / 0.14), 0 2px 6px -2px …` | Выпадающие меню, модальные окна, тосты |

Всё остальное разделяется границей `1px`, а не тенью.

## Компоненты

Библиотека в [`src/components/ui/`](../src/components/ui/). Ни один компонент не содержит зашитого пользовательского текста — все подписи приходят пропсами, а текст берётся из словарей `src/lib/i18n/messages/`.

| Компонент | Ключевые пропсы |
| --- | --- |
| `Button` | `variant: primary\|secondary\|outline\|ghost\|destructive\|link`, `size: sm\|md\|lg\|icon`, `loading`, `fullWidth`. Экспортирует `buttonVariants()` для стилизации `<Link>` |
| `Input` / `Textarea` / `Select` | `invalid`. `Select` — нативный `<select>`: даёт правильную клавиатуру и полную доступность бесплатно |
| `Checkbox` / `CheckboxField` | `label`, `hint`, `error`; строка высотой 44px |
| `RadioGroup` | `options: {value,label,hint?,icon?}[]`, `columns` — карточки с настоящим `<input type=radio>` внутри |
| `Switch` | `role="switch"`, `aria-checked` |
| `Field` / `FieldSet` | Универсальная строка формы: подпись, подсказка, ошибка (`role="alert"`, `aria-live`). Ошибка заменяет подсказку |
| `Card` + `CardHeader/Title/Description/Content/Footer` | `interactive` добавляет мягкий hover без сдвига и масштабирования |
| `Badge` / `StatusBadge` | `StatusBadge` знает все 30 статусов товара, заявки, предложения, сделки и документа |
| `Alert` | `variant: info\|success\|warning\|destructive` |
| `Dialog` / `Sheet` | На нативном `<dialog>` + `showModal()`: настоящая ловушка фокуса, инертность страницы и верхний слой без библиотек |
| `Tabs` | `role="tablist"`, навигация стрелками, горизонтальная прокрутка на телефоне |
| `Skeleton` (+ `SkeletonText/Card/ProductCard/Table`) | Каркасы загрузки |
| `EmptyState` / `ErrorState` | Принимают уже человеческий текст — технические сообщения сюда не попадают |
| `Avatar`, `Rating`, `RatingInput` | `Rating` сообщает число текстом, звёзды `aria-hidden` |
| `Pagination`, `Breadcrumbs` | Настоящие `<nav aria-label>`, `aria-current="page"` |
| `Tooltip` | Открывается и по наведению, и по фокусу с клавиатуры |
| `ToastProvider` / `useToast` | Область `aria-live="polite"`, автоскрытие 5с, пауза при наведении |
| `Table` + `TableScroll` | Горизонтальная прокрутка обёрткой, а не страницей |
| `ProgressSteps` | Индикатор многошаговых форм; на телефоне — компактная строка «Шаг 2 из 7» |

Отдельно, за пределами `ui/`:

- `CategoryPicker` — умный выбор категории: подсказки с задержкой 250 мс, одна рекомендация с кнопкой «Выбрать другую», просмотр всего дерева, показ выбранного пути. Категория **никогда** не назначается без подтверждения.
- `AttributeFields` — зависимые характеристики: набор полей приходит с сервера по выбранной категории, ничего не зашито в код.

## Состояния экранов

Каждая страница обязана реализовать все применимые состояния:

| Состояние | Реализация |
| --- | --- |
| Загрузка | `loading.tsx` рядом с `page.tsx` |
| Skeleton | Каркас повторяет форму будущего контента, чтобы страница не прыгала |
| Пусто | `EmptyState`: иконка, заголовок, объяснение, действие |
| Нет результатов | Отдельно от «пусто»: подсказка исправить запрос + сброс фильтров |
| Ошибка | `error.tsx` — понятная фраза, кнопка «Обновить». Техническая причина уходит в консоль и в репортер |
| Успех | Тост или встроенное сообщение |
| Нет связи | Понятный текст, предложение повторить |

Формула текста для пустого состояния — заголовок «что происходит», строка «что это даст», кнопка «что сделать»:

> **У вас пока нет объявлений**
> Добавьте первый товар, чтобы покупатели могли найти вашу компанию.
> `[ Добавить товар ]`

Пользователю **никогда** не показываются `Error 500`, `Mutation failed`, `Invalid request` и подобное. Server actions возвращают ключ словаря, а не текст, поэтому сообщение всегда на языке пользователя.

## Анимации

Только функциональные, длительностью 150–250 мс:

| Ключ | Длительность | Где |
| --- | --- | --- |
| `animate-fade-in` | 160 мс | Появление подложки |
| `animate-slide-up` | 180 мс | Меню, модальные окна |
| `animate-slide-in-bottom` | 220 мс | Нижняя шторка на телефоне |
| `animate-shimmer` | 1.6 с, цикл | Только skeleton |

`globals.css` содержит блок `@media (prefers-reduced-motion: reduce)`, который сводит все длительности к 0.01 мс и отключает плавную прокрутку. Смена состояния сохраняется — исчезает только движение.

## Адаптивность

Mobile-first. Проверяемые ширины: **320, 375, 390, 768, 1024, 1280, 1440**.

Правила для телефона:

- Карточки в одну колонку на 320px.
- Формы на всю ширину.
- Фильтры — в нижней шторке (`Sheet`), а не в сжатой боковой панели.
- Таблицы превращаются в карточки. Это требование, а не рекомендация: горизонтальная прокрутка таблицы на телефоне нечитаема.
- Нижняя навигация фиксированная; контент получает `.pb-safe-nav` — высота панели плюс `env(safe-area-inset-bottom)`, поэтому панель **никогда не перекрывает** последнюю строку или залипшую кнопку.
- Страница не должна прокручиваться по горизонтали ни на одной из проверяемых ширин; широкий контент прокручивается внутри своей обёртки.

## Доступность

| Требование | Как выполнено |
| --- | --- |
| Контраст | Все текстовые пары ≥ 4.5:1, проверено выше |
| Клавиатура | Все действия достижимы; `Dialog`/`Sheet` на нативном `<dialog>` дают ловушку фокуса и возврат фокуса на триггер |
| Видимый фокус | Глобальное правило `:focus-visible` с кольцом и отступом. Обводка нигде не убирается — только перерисовывается |
| Подписи | Каждое поле имеет `<label>`; иконочные кнопки — `aria-label` |
| Alt-тексты | У всех изображений; декоративные помечены `aria-hidden` |
| Семантика | `<nav>`, `<main>`, `<article>`, `<fieldset>/<legend>`, `<th scope>` |
| Зоны нажатия | Минимум 44×44px на телефоне |
| Не только цвет | Статус всегда цвет + текст; ошибка поля — иконка + текст + `role="alert"` |
| Пропуск к содержимому | Первый фокусируемый элемент страницы, появляется при фокусе |
| Динамика | `aria-live="polite"` на списке сообщений, результатах действий и тостах |
